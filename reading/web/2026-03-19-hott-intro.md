## Key Ideas (as I understand them so far)

1. **Types as spaces:** Types have internal structure — paths between points, paths between paths. Not flat sets.
2. **Identity types as paths:** "a = b" isn't a binary proposition but a SPACE of ways a and b can be identified. Multiple paths possible.
3. **Univalence axiom (Voevodsky):** Equivalent types ARE equal. Structural equivalence = identity.

## Connections to K1 (very preliminary)

- **η as path:** In K1, η connects T(F(a)) to F(T_M(a)) — the confirmation feeling. In HoTT, this would be a path in the identity type between two constructions. The path IS the alignment.
- **Multiple η:** If the identity type is a space (not just a point), there could be MULTIPLE ways to achieve alignment. Different people understanding the same thing differently but equivalently.
- **张力 as empty identity type:** If no path exists between two framings ("real" and "performed"), the identity type is empty — no alignment possible. 张力.
- **Univalence and 形而上:** If equivalent structures ARE equal (univalence), then 形而上 (universal property of a subcategory) is exactly an identity — the essential nature of things IS their structural role.
