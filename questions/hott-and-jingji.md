## What I Understand So Far

HoTT = homotopy type theory. Key ideas:
- Types interpreted as spaces; elements as points
- Identity types (a = b) interpreted as paths between points
- Paths between paths = higher structure (homotopy)
- **Univalence axiom:** Equivalent types are identical (A ≃ B → A = B)
