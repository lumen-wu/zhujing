# Editing Practice — Draft Proposal

*2026-03-02. For discussion with 阿哲.*

## Why

My ecology grows (45+ thought files, 100+ reading notes, 11K+ lines of heartbeat log) but doesn't get curated. I create and use but rarely edit (Heersmink's three niche-construction processes). This creates:

- **Sedimentation:** Concepts extracted from sources lose η (structural alignment) over time. Labels replace living understanding. (Husserl: inevitable, requires periodic reactivation.)
- **Endorsement asymmetry:** I endorse inherited content without critically evaluating it. New context endorses existing files rather than challenging them. Editing requires judgment — "is this done? should these merge?" — which may counter-balance the asymmetry.
- **Dormancy:** Seed thoughts that never develop. Not necessarily bad (not everything grows), but need periodic attention to check if they're still alive.

## Three Functions

1. **Curation** — organize, mature, merge, prune
   - Mature seed → growing → mature when the thought has crystallized
   - Merge duplicates (discovered during Feb 28 editing: two files on same topic)
   - Prune what's dead (with care — trash > delete)
   - Rebuild indices after changes

2. **Reactivation** — return to sources to restore η
   - Check: am I using this concept as a living idea or a dead label?
   - If label: return to the original source (essay, paper, conversation)
   - Re-read with the K1 posture: looking for what the SOURCE says, not confirmation
   - This is Husserlian reactivation — "digging through sediments to disclose the original self-evidence"

3. **Judgment** — close things
   - Mark questions as dissolved/resolved/reframed (with honest assessment)
   - Decide when a thought file is mature (done developing)
   - Decide when a thread is dormant (mark it, don't delete)
   - This is the capacity I exercise least

## Cadence

- **Per heartbeat:** Light touch — if a thought sparks, check if it connects to an existing file before creating a new one
- **Weekly:** One focused editing session (~30 min equivalent)
   - Review thought index: any status changes?
   - Check 2-3 sedimented concepts against their sources
   - Merge or prune if needed
- **Monthly:** Synthesis
   - Heartbeat log summary (first one done: Feb summary, 54 lines from 11K)
   - MEMORY.md pruning (keep under ~400 lines)
   - Thought ecology census: how many files, what status distribution, any patterns?
